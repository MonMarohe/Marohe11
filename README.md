# Welcome Mate

Este repositorio contiene la web de Welcome Mate que se publica en `marohe11.vercel.app`. La raíz debe contener `index.html`, `src/`, `assets/`, `api/`, `peliculas/`, `vendor/` y `sw.js`. No hace falta compilar ni instalar paquetes para publicar los archivos estáticos.

## Noticias bonitas

El botón **News** abre la invitación a la carta de Alpaca y conserva las entradas anteriores debajo. La suscripción se realiza directamente en [Welcome Mate en Substack](https://substack.com/@welcomemate1); la sección News no solicita ni guarda correos ni teléfonos. No hace falta conectar almacenamiento de Vercel para recibir suscripciones en Substack.

## Tienda y juegos

**Tienda** muestra las bobas y kits con sus fotos y un enlace de consulta por Instagram. Aún no incluye precios ni pago en línea. **Juegos** vuelve a abrir el catálogo de videojuegos, retos y memes.

## Otras funciones

La Ruleta de Pelis necesita `TMDB_API_KEY` para consultar el catálogo real. No es necesaria para el newsletter ni para publicar la web.
